APDC RESULTS UPDATE
===================

목적
- 기존 디자인/기능은 유지
- 메뉴 순서: ENTRY SEARCH → TIMETABLE → RESULTS
- RESULTS는 업로드된 '2026 APDC 시상 출력용.xlsx'의 '전체 파이널 결과' 시트를 기준으로 사용
- RESULTS는 섹션별 → 종목별 → 순위별로 구분
- 이름(부분검색/대소문자 무관) 또는 등번호(정확히 일치)로 검색
- 메달/트로피/상금 지급 대상은 이모티콘으로 표시
  · 🏆 = 트로피
  · 🏅 = 메달
  · 💵 = 상금

업로드할 파일
1. entry.html        (기존 파일 교체)
2. timetable.html    (기존 파일 교체)
3. results.html      (새 파일)
4. results.js        (새 파일)
5. results.json      (새 파일)

주의
- style.css / timetable-judge.css / script.js / timetable.js 등 기존 디자인 및 기능 파일은 수정하지 않았습니다.
- results.json의 순위/이름/등번호/시상품 표시는 엑셀 값을 임의 수정하지 않았습니다.
